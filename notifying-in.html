Building Notifying.in from a simple event idea into a product system.

A 0→1 event discovery and notification platform for Indian users. The work expanded from event organisation into subscriptions, notification infrastructure, admin operations, advertising and search-focused growth.

01 / Problem

The information existed. The experience was fragmented.

The product needed a simple way to help people identify what matters today, understand upcoming events and receive timely reminders without requiring a complex account journey.

Starting point

The product concept centred on Indian events such as bank holidays, state holidays, festivals, dry days and fasting days, organised so users could browse by date, state and category.

The hard part was not just showing a calendar. It was creating a repeatable system that could support changing event data, user subscriptions, notifications, administration and future monetisation.

02 / Product system

I treated it as a system, not a page.

Each feature was connected to a larger product loop so that discovery, subscription, notification and operations could evolve together.

01

Structure the information

Defined the core event model around states, categories and event records so the same information could power browsing, event pages and notifications.

02

Reduce subscription friction

Built a web-push flow so users could subscribe from the website without depending on a mandatory account system.

03

Make notifications operational

Added a custom push server and notification handling around subscriptions, payloads and expired subscriptions, followed by notification logs and custom sending from the admin side.

04

Build the operating layer

Created admin workflows for events and system management so the product could be maintained as content and notification volume changed.

05

Add the business model

Developed an ad-management layer supporting custom banners, native placements, affiliate/sponsored concepts and Google AdSense, with context-aware responsive placements.

Architecture

Technology supported the product model.

The implementation combined front-end pages with PHP/MySQL data handling, a Node.js/Express notification service using Web Push, service-worker functionality, and a WordPress blog layer for future content growth.

Product execution

Scope was managed in explicit phases.

The product progressed through defined phases covering authentication, UI/UX polish, notification logs, event administration and ads/monetisation. The next planned layers are search optimisation, automated notifications and the content platform.
